The UPS reports no charge percentage; it is estimated from the battery voltage. Under load on battery the estimate is rough. The runtime is estimated from charge and load (800 W, 12 V / 9 Ah battery).

Setup

  1. Create a boot task that starts the driver as root:
    Control Panel → Task Scheduler → Create → Triggered Task → User-defined script · User: root · Event: Boot-up · Run command:
    …
  2. Select the new task and click “Run” once (or restart the NAS).
  3. Control Panel → Hardware & Power → UPS: leave UPS support off. This package powers the NAS off itself (DSM's standby would never wake up again).
  4. Control Panel → Hardware & Power → General: enable “Restart automatically when power supply issue is fixed” and “Enable WOL on LAN 1”.
  5. •Wake-up after power returns: a smart plug with ESPHome (e.g. NOUS A1T) in a wall socket not on the UPS, on the same Wi-Fi/LAN. Add this to the plug’s ESPHome configuration (merge on_boot into the existing esphome: section) and flash it:
    …
    When mains returns the plug boots and sends a Wake-on-LAN packet every 30 s for about 10 minutes.

Before uninstalling the package: run the same task once with “remove” instead of “start” at the end of the command, then delete the task.

Settings & log

Empty fields are determined automatically: IP, voltage divisor (from the nominal voltage) and full/empty thresholds (13.1 V / 10.4 V per 12 V). Run the boot task again after saving.
